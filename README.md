A fast, byte-identical drop-in for marked 18.1.3: it renders Markdown to exactly the HTML that marked produces with its default options, but faster — a hand-written fast renderer for the common constructs, falling back to the vendored marked itself for anything else.

## Run it

```sh
MAKEFUN_INPUT_DIR=./practice/input MAKEFUN_OUTPUT_DIR=./out node main.ts
```
